设计原则

这五条决定了后续迭代不能破坏什么

① 零直连

代理开启时，没有端口就失败（ERR_PROXY_REQUIRED_FAIL_CLOSED / 503），不存在静默回退全局 fetch。

② 零依赖

只用 Node 内置模块；WebSocket 客户端、代理 CONNECT、锁与调度均自实现，安装副本不需要 node_modules。

③ 密钥不出本机

API Key 只存 state.json（0600）；面板经本地服务访问，浏览器不接触 Key。

④ 写操作可重放

生命周期与快照写操作带 Idempotency-Key；删除必须 X-Confirm-Delete 与名称确认。

⑤ 能力同源

面板、MCP、cron 脚本共用 lib/，避免三套行为漂移；通用模块禁止反向依赖平台客户端。

零直连传输

P0-1 · v1.6.0 起 · v1.7.0 出口移交 Egress Matrix

改造前

  • fetchFor() 语义是“有端口就用”，无端口静默返回 undefined。
  • InstaboxClient 回退 globalThis.fetch。
  • 终端 WebSocket 无 agent，始终直连。
  • recycle 的列表/快照/电源与 keepalive 释放存在直连分支。

改造后

  • requireFetchFor() 无端口抛 ProxyRequiredError。
  • 错误码 ERR_PROXY_REQUIRED_FAIL_CLOSED，HTTP 503。
  • REST 与 ws/wss 共用同一 CONNECT 隧道。
  • 代理关闭才允许直连（显式退出，不是泄漏）。

出口委托与冻结

19880 是出口唯一真源 · 19882 是隧道控制面

Egress Matrix（19880）

  • 账号固定 matrixSlotId（slot-001~250）与 egressPort（24001–24250）。
  • 每个控制面请求带 X-OC-Routing-Plane: STRICT_CONTROL 与槽位 Proxy-Authorization。
  • 发包前 assertSlotUsable() 核验实时健康态；WARP_OVERFLOW / ROTATING / QUARANTINED 直接 503。
  • 守 WS：PRE_ROTATION_FREEZE 暂停该槽 keepalive/jobs、销毁连接池并回 ack-freeze；POST_ROTATION_RESUME 刷新指纹并恢复。

Cloudflare Bridge（19882）

  • 机器 RUNNING 后 POST /api/v1/cf/tunnel/provision。
  • 隧道 token 只经一次 noHistory exec 注入实例，不写状态、不进日志与响应。
  • 实例内执行 cloudflared tunnel run --token … --no-autoupdate --protocol http2。
  • 回收/删除前 POST /api/v1/cf/tunnel/teardown；404 视为已释放。

槽位解析顺序

// 1) settings.proxy.slots[alias] 固定槽位
// 2) settings.proxy.ports[alias] ∈ 24001–24250
slot = slot-{index:03d}
port = 24000 + index
// 3) 启用账号 alias 排序后 index + 1
// candidate: true 时把未入库 alias 插入排序

槽位上限 250，超额抛 matrix_slot_exhausted；委托模式下非矩阵端口直接拒绝，只有 --standalone-fallback 才本地起 sing-box。

WebSocket 隧道

不复制代理逻辑，复用同一个 CONNECT 工厂

实现

  • createTunnelSocketFactory(proxy, sockets, { secure })：secure=false 时 CONNECT 成功后直接回原始 socket。
  • createTunnelAgent()：https.Agent / http.Agent 子类，覆盖 createConnection。
  • account-transport 按协议懒创建两个 Agent，maxSockets 默认 4。
  • ws.js 仅透传 options.agent，不传时行为不变。

销毁顺序

  1. 关闭 fetch 客户端（含在途请求与配额）。
  2. 销毁 secure / plain 两个 Agent。
  3. 清空残留隧道 socket。

避免 keep-alive 隧道把进程或测试挂住；closeAll() 在服务退出、脚本结束、账号端口变更时调用。

机器生命周期

租约保活、最长运行、冷却与自动回收

租约（keepalive）

  • 默认 TTL 900 秒；剩余 ≤ 50% 时续期。
  • 每 15 秒一轮，按 key 相位错开；并发 4。
  • 模式：lease / knock / both；knock 任意 HTTP 状态算成功。
  • 404 lease_not_found 只重建一次；429 保留旧到期时间并退避。
  • autoWake 默认关闭；开启后按 retryAt 走 wake → resume → start。

回收（recycle）

  • lead = maxRun 的 10%，clamp 10–30 分钟。
  • 默认最小运行 60 分钟、轮询 5 分钟、验证超时 180 秒。
  • 流程：suspend → resume → verify；verify 检查 5 个容器 + healthz。
  • 验证失败先 bootstrap 一次，再失败降级并停止重试。
  • 双入口：服务内 recycler + 独立 cron 脚本；文件锁保证单 owner。

写入安全

  • 目录 0700、文件 0600；临时文件写入后原子 rename。
  • withStateLock 串行化读改写，锁过期可接管。
  • 写操作失败不会留下半截 JSON。
  • 状态文件含 API Key，禁止提交、分享、同步到云端。

密钥与认证

  • 面板 → 服务：127.0.0.1，不使用浏览器存储持 Key。
  • 服务 → Gateway：X-API-Key: ibk_…。
  • 写操作：Idempotency-Key；删除：X-Confirm-Delete。
  • 终端 WSS：升级请求带 X-API-Key，经代理隧道。
  • Canvas 访客页：本机端口 + secret，沙箱运行。

下一批验收标准

  • SQLite 迁移后 state.json 可自动导入，回滚可导出。
  • 新增账号不改变既有账号槽位（迁移后保持）。
  • 200 账号下 keepalive tick 不产生同一秒脉冲。
  • 停 Egress Matrix（19880）时面板与 MCP 全部 503，无直连日志。

不要做

  • 不要用 Chrome UA + Node TLS 伪装浏览器。
  • 不要让多个账号共用一个出口 IP。
  • 不要把 API Key 放进 bootstrap、日志或 Canvas 页面。
  • 不要在未抓官方客户端请求前编造指纹 persona。

故障排查

先看错误码，再看日志关键词

现象可能原因处理
面板 API 返回 503 / ERR_PROXY_REQUIRED_FAIL_CLOSED代理开启但 alias 无槽位/端口保存账号或设置 proxy.slots[alias]；检查 19880 槽位状态
日志 proxy quarantined代理不可达 / CONNECT 失败修复端口后 POST /api/proxy/release 或等待半开探测
503 / ERR_EGRESS_SLOT_BLOCKED槽位 COOLDOWN / WARP_OVERFLOW / ROTATING / QUARANTINED查 instabox_matrix_slot_status 或 GET /api/v1/egress/slots；等恢复正常态，勿绕过
503 / ERR_EGRESS_UNAVAILABLE19880 未启动或不可达启动 egress matrix；恢复前保持 fail-closed
CF 操作返回 skipped19882 未启动或未配置隧道域名启动 CF bridge；在 settings.proxy.tunnels 配 hostname
日志 rotation freeze19880 正在给该槽换血无需处理；恢复事件后 keepalive/jobs 自动继续
429 / quota_exceeded平台限流或免费额度降低 rps；等待 retryAfter；检查计划配额
终端空白 / 立即重连无回放会话已回收或 1 秒内重连重新打开；等待 1 秒；检查 WSS 是否经代理
Canvas 打不开viewer 未启动 / 缺 canvas 扩展确认 canvas/viewer/server.js 存在；重试发布
自更新克隆失败私有仓库未登录先手动 git clone；或设置 PAT / git 凭据
